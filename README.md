# Eleições AABB Balsas 2026

Hotsite oficial do processo eleitoral 2026 (mandato 2027/2030) da Associação Atlética Banco do Brasil – Balsas/MA.
Conteúdo sob responsabilidade da Comissão Eleitoral.

- `public/`: os arquivos do site (página, logo e documentos oficiais em PDF).
- `wrangler.jsonc`: configuração do Cloudflare Workers.

Endereço: https://eleicoes.aabbbalsas.workers.dev

Cada atualização enviada para o branch `main` é publicada automaticamente pelo Cloudflare.
Não edite `public/` à mão: ela é gerada a partir do projeto principal.
